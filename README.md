# 🛍️ E-Commerce Website

A Full Stack E-Commerce Web Application built using **React.js**, **Django**, and **PostgreSQL**. The platform allows users to browse products, manage carts, place orders, and provides an admin panel for product and order management.

## 🚀 Tech Stack

### Frontend
- React.js
- Vite
- React Router DOM
- Tailwind CSS

### Backend
- Django
- Django REST Framework
- Python

### Database
- PostgreSQL

---

## ✨ Features

- 🔐 User Authentication & Authorization
- 🛒 Shopping Cart Management
- 📦 Product Listing & Details
- 🔍 Search & Filter Products
- ❤️ Responsive UI Design
- 📋 Order Management
- 👨‍💼 Admin Dashboard
- 🗄️ PostgreSQL Database Integration
- 🔗 REST API Integration
